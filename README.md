# DragonBallApp

Esta es una app para Android que hice en Java. Muestra una lista de personajes de Dragon Ball usando un RecyclerView.

## Cómo la hice
- Saqué los datos de la API https://dragonball-api.com
- Usé Volley para conectarme a la API y Glide para mostrar las imágenes de los personajes.
- Si toco un personaje de la lista, se abre otra pantalla donde puedo ver su información completa.
